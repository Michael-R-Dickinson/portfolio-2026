**infra/s3.tf** — create from scratch with three resources:

1. `aws_s3_bucket "portfolio"` — sets `bucket = var.bucket_name`. No ACL, no website config (OAC access only).

2. `aws_s3_bucket_public_access_block "portfolio"` — sets all four block flags to true:
   - `block_public_acls = true`
   - `block_public_policy = true`
   - `ignore_public_acls = true`
   - `restrict_public_buckets = true`
   - `bucket = aws_s3_bucket.portfolio.id`

3. `aws_s3_bucket_policy "portfolio"` — grants CloudFront OAC read access only. The policy document uses a `data "aws_iam_policy_document"` with a single `statement`:
   - `effect = "Allow"`
   - `principals { type = "Service"; identifiers = ["cloudfront.amazonaws.com"] }`
   - `actions = ["s3:GetObject"]`
   - `resources = ["${aws_s3_bucket.portfolio.arn}/*"]`
   - `condition { test = "StringEquals"; variable = "AWS:SourceArn"; values = [aws_cloudfront_distribution.portfolio.arn] }`
   - `bucket = aws_s3_bucket.portfolio.id`
   - `policy = data.aws_iam_policy_document.portfolio_bucket_policy.json`

   Note: The bucket policy references `aws_cloudfront_distribution.portfolio.arn` which is defined in cloudfront.tf. Terraform resolves cross-file references automatically — this is intentional and correct.

Place the `data "aws_iam_policy_document"` block before the `aws_s3_bucket_policy` resource in s3.tf for readability.

<task type="auto">
  <name>Task 2: Create cloudfront.tf with OAC and distribution</name>
  <files>infra/cloudfront.tf</files>
  <action>
Create infra/cloudfront.tf from scratch. Structure:

**1. locals block at the top** — define SPA error response rules:

```hcl
locals {
  spa_error_responses = [
    {
      error_code            = 403
      response_code         = 200
      response_page_path    = "/index.html"
      error_caching_min_ttl = 0
    },
    {
      error_code            = 404
      response_code         = 200
      response_page_path    = "/index.html"
      error_caching_min_ttl = 0
    },
  ]
}
```

**2. `aws_cloudfront_origin_access_control "portfolio"`**:
- `name = "${var.bucket_name}-oac"`
- `description = "OAC for portfolio S3 bucket"`
- `origin_access_control_origin_type = "s3"`
- `signing_behavior = "always"`
- `signing_protocol = "sigv4"`

**3. `aws_cloudfront_distribution "portfolio"`**:

```hcl
resource "aws_cloudfront_distribution" "portfolio" {
  enabled             = true
  default_root_object = "index.html"
  price_class         = "PriceClass_100"  # US, Canada, Europe only — cheapest

  origin {
    domain_name              = aws_s3_bucket.portfolio.bucket_regional_domain_name
    origin_id                = "S3-${var.bucket_name}"
    origin_access_control_id = aws_cloudfront_origin_access_control.portfolio.id
  }

  default_cache_behavior {
    allowed_methods        = ["GET", "HEAD"]
    cached_methods         = ["GET", "HEAD"]
    target_origin_id       = "S3-${var.bucket_name}"
    viewer_protocol_policy = "redirect-to-https"

    forwarded_values {
      query_string = false
      cookies {
        forward = "none"
      }
    }
  }

  dynamic "custom_error_response" {
    for_each = local.spa_error_responses
    content {
      error_code            = custom_error_response.value.error_code
      response_code         = custom_error_response.value.response_code
      response_page_path    = custom_error_response.value.response_page_path
      error_caching_min_ttl = custom_error_response.value.error_caching_min_ttl
    }
  }

  restrictions {
    geo_restriction {
      restriction_type = "none"
    }
  }

  viewer_certificate {
    cloudfront_default_certificate = true
  }
}
```
