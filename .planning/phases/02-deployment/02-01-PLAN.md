  <action>
Create `infra/deploy.tf` containing a single `null_resource "deploy"` with three `local-exec` provisioners that run in order.

The `null_resource` must use `triggers = { always_run = timestamp() }` so every `tofu apply` re-runs the provisioners. This is the standard pattern for deploy null_resources — it means `tofu plan` will always show a change, which is intentional and correct behavior for a deploy resource.

The three provisioners, in order:

**1. pnpm build**
```hcl
provisioner "local-exec" {
  working_dir = "${path.root}/../frontend"
  command     = "pnpm build"
}
```
`path.root` is the `infra/` directory, so `../frontend` resolves to the frontend directory. `working_dir` is relative to the Terraform working directory (`infra/`), so `../frontend` is correct.

**2. aws s3 sync**
```hcl
provisioner "local-exec" {
  command = "aws s3 sync ${path.root}/../frontend/dist s3://${aws_s3_bucket.portfolio.bucket} --delete"
}
```
`--delete` removes files from S3 that no longer exist in dist. No `working_dir` needed here — the full path is in the command.

**3. CloudFront invalidation**
```hcl
provisioner "local-exec" {
  command = "aws cloudfront create-invalidation --distribution-id ${aws_cloudfront_distribution.portfolio.id} --paths '/*'"
}
```
